---

## What is this?

This is a small, clean blog interface created using HTML, CSS, JavaScript, and Bootstrap.

But more than that —  
it’s a practice space.

A place where structure meets styling.  
Where JavaScript adds life to static pages.  
Where responsiveness is not optional.

---

## Why I Built It

I wanted to move beyond just writing HTML and actually structure a small, realistic website.

Instead of:
- dumping everything into one file
- hardcoding repetitive content

I separated:
- structure (HTML)
- design (CSS)
- behavior (JavaScript)

And made blog posts render dynamically.

Small decision.  
Big difference.

---

## What It Demonstrates

• Clean folder organization  
• Responsive layout using Bootstrap  
• DOM manipulation with JavaScript  
• Simple UI interactions  
• Basic front-end architecture thinking  

Not complicated.  
Just intentional.

---

## How It Works

The page loads.  
JavaScript reads a list of blog objects.  
Each object becomes a styled card.  
Hover effects add motion.  
The UI stays responsive across devices.

That’s it.

---

## The Idea Behind It

Good design is not about adding more.  
It’s about removing what isn’t needed.

This project reflects that mindset.
